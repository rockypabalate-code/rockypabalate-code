HOW TO ADD YOUR NEW GITHUB PROFILE

GitHub username: rockypabalate-code

1. Log in to GitHub.
2. Create a PUBLIC repository with the EXACT name: rockypabalate-code
   (It must match your GitHub username to appear on your profile.)
3. Upload these two files, preserving the paths:
   - README.md
   - assets/hero.svg
4. Commit the changes to your main branch.
5. Refresh https://github.com/rockypabalate-code

If the repository already exists, add or replace README.md and add
assets/hero.svg to the existing repository instead.

Optional: Edit README.md text to change the bio or project descriptions.
Badge images are supplied by shields.io, so internet access is needed
for those badges. The main header image is in your own repository.
